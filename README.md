# Nepal Earthquake 2015 Visualization

## Overview

The **April 2015 Nepal Earthquake** was one of the deadliest natural disasters in Nepal's history, claiming over **9,000 lives** and injuring more than **23,000 people**.

This interactive visualization explores the earthquake's impact across Nepal's districts by presenting:

- 🌍 **Total number of earthquakes**, including aftershocks, recorded in each affected district.
- 📈 **Maximum earthquake magnitude** experienced by each district.
- 👥 **Human casualties**, including deaths and injuries, visualized using interactive bar charts.
- 🏠 **Infrastructure damage** across districts, enabling comparison of the earthquake's impact.

The visualization provides an intuitive way to explore both the seismic activity and the resulting human and infrastructure losses at the district level.
